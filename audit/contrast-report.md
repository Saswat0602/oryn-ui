## Methodology

Contrast ratio computed per [WCAG 2.1 §1.4.3](https://www.w3.org/TR/WCAG21/#contrast-minimum):

```
relative_luminance(c) = 0.2126 R + 0.7152 G + 0.0722 B  (linearised sRGB)
contrast_ratio(L1, L2) = (lighter + 0.05) / (darker + 0.05)
```
